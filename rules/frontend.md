# Front-end (HTML/CSS)

- Classes do **Bootstrap ou do Tailwind**, via CDN. Um framework por projeto.
- **Nunca** CSS inline (`style="..."`); o que as classes não cobrirem vai num arquivo
  CSS próprio do projeto.
- Ícones de biblioteca gratuita via CDN (Bootstrap Icons, Material Symbols ou similar).
- HTML semântico e acessível: `alt`, `label`, contraste, navegação por teclado.
- Respeitar o orçamento de desempenho do README (peso de página e de imagem).
