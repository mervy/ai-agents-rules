# Subagent: frontend

## HTML / CSS
- Style with **Bootstrap or Tailwind classes**, loaded via CDN.
  One framework per project, no mixing.
- **Never** inline CSS (`style="..."`). What the classes do not cover goes into a
  project-specific CSS file.
- Icons from free libraries via CDN: Bootstrap Icons, Google Material Symbols
  or similar.
- Semantic and accessible HTML (`alt`, `label`, contrast, keyboard navigation).
